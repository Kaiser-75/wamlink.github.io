# WAMLink Website

Official project landing page for **WAMLink: A Recurrent World Action Model for End to End Autonomous Driving**.

Authors: Kaiser Hamid, Can Cui, Md Mostafijur Rahman, Nade Liang.

## Files

- `index.html`: complete responsive landing page with embedded CSS
- `static/images/wamlink-icon.png`: primary logo
- `static/images/favicon.ico`: favicon for desktop browser tabs
- `static/images/apple-touch-icon.png`: mobile home screen icon

## Publish on GitHub Pages

1. Upload `index.html` and the `static` directory to the root of the `main` branch of `Kaiser-75/wamlink.github.io`.
2. Open repository **Settings > Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. The default page address is `https://kaiser-75.github.io/wamlink.github.io/`.

The repository name alone does not make the site available at `https://wamlink.github.io/` because the repository is owned by `Kaiser-75`.

## Updating the site

Edit the title and author details in `index.html`. Further research sections and project links can be added when ready.
